# Support

Variable Thema is free software distributed under the GNU GPL version 2 or
later.

## Before requesting help

1. Confirm that the issue occurs with a supported WordPress and PHP version.
2. Test with the Variable Thema parent theme where practical.
3. Check existing issues and the project documentation.
4. Record clear reproduction steps and relevant, non-sensitive environment
   details.

## Where to ask

- Use a **Bug report** for reproducible defects in Variable Thema.
- Use a **Compatibility report** for a WordPress, PHP, browser, or Skin
  integration problem.
- Use a **Feature request** for a proposed generic presentation improvement.
- Follow [SECURITY.md](SECURITY.md) for suspected vulnerabilities.

GitHub issues are not suitable for credentials, private URLs, customer data,
database exports, or confidential logs.

## Scope of community support

Project support covers the Variable Thema parent theme and its documented
public contracts. It does not guarantee assistance with:

- A third-party or site-specific Skin.
- Custom site design or content production.
- Plugin configuration or business functionality.
- Hosting, server, DNS, or email configuration.
- Data migration, incident response, or production operations.

Responses are provided as maintainer capacity allows; no response time or
resolution is guaranteed.
